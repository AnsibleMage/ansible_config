# Obsidian & Antigravity 통합 비전: "Living Second Brain"

옵시디언(Obsidian)과 안티그래비티(Antigravity)의 통합은 정적인 **'제2의 뇌'(Second Brain)**를 동적인 **'실행하는 뇌'(Executing Brain)**로 진화시키는 핵심 전략입니다.

단순한 백업을 넘어, 두 시스템을 유기적으로 결합하는 3단계 통합 모델을 제안합니다.

## 1. 물리적 통합 (The Shared Workspace)
**개념**: 안티그래비티의 "작업 기억(Brain)"을 옵시디언의 "장기 기억(Vault)" 내부로 가져옵니다.
- **실행 방안**:
  - `C:\Users\name\.gemini\antigravity\brain` 폴더를 옵시디언 볼트 내 `00_Antigravity_Brain` 폴더로 이동하거나 심볼릭 링크(Symbolic Link)를 생성합니다.
- **효과**:
  - 안티그래비티가 생성하는 `task.md`, `implementation_plan.md`를 옵시디언에서 실시간으로 보고 편집할 수 있습니다.
  - 옵시디언의 Graph View에서 에이전트의 작업 내역이 지식과 어떻게 연결되는지 시각화할 수 있습니다.

## 2. 문맥적 통합 (The Context Engine)
**개념**: 옵시디언을 에이전트의 **"판단 기준(Rulebook)"**으로 활용합니다.
- **실행 방안**:
  - `GEMINI.md` (전역 설정)를 볼트 최상위에 두고 관리합니다.
  - 프로젝트별 요구사항(Requirements)을 옵시디언 노트로 작성하고, 작업 시작 시 에이전트에게 "이 노트를 읽고 시작해"라고 지시합니다.
- **효과**:
  - 에이전트가 사용자의 생각과 철학이 담긴 노트를 기반으로 코딩하게 됩니다. (RAG 시스템의 개인화)

## 3. 프로세스 통합 (The Action Dashboard)
**개념**: 옵시디언을 **"에이전트 관제 센터(Command Center)"**로 사용합니다.
- **실행 방안**:
  - **Daily Note 연동**: 데일리 노트에 `- [ ] 오늘 할 일`을 적으면 에이전트가 이를 인식하여 작업을 수행합니다.
  - **Canvas 활용**: 복잡한 아키텍처를 옵시디언 캔버스로 그리면, 에이전트가 이를 읽고 폴더 구조를 생성하거나 코드를 짭니다.
  - **결과 기록**: 에이전트가 작업 완료 후 `walkthrough.md`를 관련 프로젝트 폴더에 자동으로 아카이빙합니다.

## 제안하는 첫 걸음
가장 쉽고 강력한 **"물리적 통합"**부터 시작하는 것을 추천합니다.
1. 옵시디언 볼트에 `Antigravity` 폴더 생성.
2. 현재 진행 중인 에이전트 작업(`brain`)을 해당 폴더에서 볼 수 있도록 설정.

이 방식에 동의하신다면, 제가 **현재의 작업 로그들을 옵시디언 볼트 내의 지정된 폴더로 정리해서 옮겨드릴 수 있습니다.**

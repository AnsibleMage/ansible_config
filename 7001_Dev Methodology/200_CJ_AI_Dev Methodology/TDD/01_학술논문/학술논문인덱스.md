- **저자:** Noble Saji Mathews, Meiyappan Nagappan (University of Waterloo)
- **학술지:** ACM Transactions (2024)
- **핵심 내용:**
  - TDD 원칙을 LLM 코드 생성에 적용
  - GPT-4, Llama 3에서 실험
  - MBPP, HumanEval 벤치마크 사용
- **핵심 발견:** 테스트 포함 시 일관되게 더 많은 문제 해결 ✅
- **영향력:** 이후 연구의 기초 논문
- **파일 링크:** [[./2402.13521_TDD_for_CodeGen]]

#### 2. **TestART: Improving LLM-based Unit Testing via Co-evolution** ⭐⭐⭐⭐⭐
- **arXiv ID:** 2408.03095 (2024-08-10, v6: 최신)
- **저자:** Nanjing University, Huawei Cloud Computing
- **컨퍼런스:** ACM Transactions on Software Engineering and Methodology (2024)
- **핵심 내용:**
  - 생성 + 수리(repair) 루프 적용
  - 템플릿 기반 수리 전략
  - 커버리지 안내 피드백
- **핵심 발견:**
  - **통과율:** 78.55% (ChatGPT-4.0 대비 18% 향상)
  - **커버리지:** 90.96% 라인 커버리지
  - **비교:** EvoSuite와 유사 성능, 테스트 케이스 절반
- **실용성:** 높음 (산업 적용 가능)
- **파일 링크:** [[./2408.03095_TestART]]

---

#### 3. **CoverUp: Coverage-Guided LLM-Based Test Generation** ⭐⭐⭐⭐
- **arXiv ID:** 2403.16218 (2024-03-18)
- **저자:** 여러 기관 협력
- **핵심 내용:**
  - 커버리지 분석으로 프롬프트 개선
  - 반복적 피드백 루프
  - 실제 Python 코드베이스 테스트
- **핵심 발견:**
  - **라인+브랜치 커버리지:** 80% (vs. CodaMosa 47%)
  - **MuTAP 대비:** 89% (vs. 77%)
- **기술 수준:** 높음 (프로덕션 준비 완료)
- **파일 링크:** [[./2403.16218_CoverUp]]

---

#### 4. **SymPrompt: Code-Aware Prompting for Coverage-Guided Test Generation** ⭐⭐⭐⭐
- **arXiv ID:** 2402.00097 (2024-02-01)
- **저자:** 여러 기관
- **핵심 내용:**
  - 프롬프트 엔지니어링 전략
  - 다단계 추론 활용
  - 실행 경로 기반 가이드
- **핵심 발견:**
  - **CodeGen2:** 5배 향상 (정답 생성)
  - **GPT-4:** 2배 커버리지 향상
  - **상대 커버리지:** 26% 개선
- **혁신성:** 높음 (새로운 프롬프팅 패러다임)
- **파일 링크:** [[./2402.00097_SymPrompt]]

#### 5. **Mutation-Guided LLM-based Test Generation at Meta** ⭐⭐⭐⭐⭐
- **arXiv ID:** 2501.12862 (2025-01-22) [LATEST]
- **저자:** Meta Platforms (ACH 시스템)
- **컨퍼런스:** FSE 2025 (ACM International Conference on Foundations of Software Engineering)
- **핵심 내용:**
  - 변이 테스트 기반 생성
  - 개인정보보호 테스트 사례
  - 동등 변이 감지 에이전트
- **핵심 발견:**
  - **생성 변이:** 9,095개
  - **개인정보보호 테스트:** 571개
  - **엔지니어 수용률:** 73% (Messenger/WhatsApp)
  - **동등 변이 감지:** 정밀도 0.79, 재현율 0.47
- **실제 영향:** 매우 높음 (Meta 플랫폼 배포)
- **파일 링크:** [[./2501.12862_Meta_ACH]]

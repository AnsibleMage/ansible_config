# REVIEW.md — Global Default Review Rules

## Critical (필수 수정 — 통과 전까지 병합 차단)
- 데이터베이스 변경 시 하위 호환성 보장할 것
- 외부 API 호출 시 타임아웃과 재시도 로직 포함할 것
- 인증/인가 로직 변경 시 기존 테스트 전체 통과 확인할 것
- 환경변수(.env) 참조 시 기본값 설정 확인할 것
- 보안 파일(.env, .secret, credentials) 커밋 금지
- SQL 인젝션, XSS, 인증 우회 취약점 탐지 시 즉시 차단

## Warning (권장 수정 — 사유 기재 시 무시 가능)
- 매직 넘버 금지, 상수로 추출할 것
- 함수 30줄 초과 시 분리 권장
- 주석이 없는 복잡한 비즈니스 로직 경고
- 미사용 import/변수 제거
- 중복 코드 3회 이상 반복 시 추출 권장
- 에러 처리 없이 외부 호출하는 코드 경고

## Info (참고 — 현재 변경과 무관한 기존 문제)
- 네이밍 컨벤션 준수 (camelCase / snake_case)
- 일관된 에러 처리 패턴 사용
- 로깅 레벨 적절성 확인
- 기존 코드의 내재적 버그 보고

프로젝트 리스크 매트릭스를 생성/업데이트해주세요.

## 대상
$ARGUMENTS (프로젝트명, 신규 생성 또는 업데이트)

## 수행 작업
1. 기존 리스크 매트릭스 확인 (있으면 업데이트, 없으면 신규)
2. 프로젝트 정보 기반 리스크 식별
3. 리스크 평가 (확률 x 영향)
4. 대응 전략 수립
5. 리스크 매트릭스 문서 생성 (/xlsx 또는 /docx 활용)

## 리스크 매트릭스 구조

### 1. 리스크 등록부 (Risk Register)

```markdown
# 프로젝트 리스크 매트릭스

## 기본 정보
| 항목 | 내용 |
|------|------|
| 프로젝트명 | |
| 작성일 | YYYY-MM-DD |
| 최종 업데이트 | YYYY-MM-DD |
| PM | |
| 리뷰 주기 | 주간/격주/월간 |

## 리스크 등록부
| ID | 카테고리 | 리스크 설명 | 확률 | 영향 | 등급 | 담당 | 대응전략 | 상태 | 트리거 |
|----|----------|------------|------|------|------|------|----------|------|--------|
| R-001 | | | H/M/L | H/M/L | | | | Open/Closed | |
```

### 2. 리스크 카테고리

| 카테고리 | 설명 | 예시 |
|----------|------|------|
| **기술 (Technical)** | 기술적 실현 가능성 | 기술 복잡도, 신기술 미검증, 통합 이슈 |
| **일정 (Schedule)** | 프로젝트 일정 관련 | 납기 지연, 외부 의존성, 병목 |
| **비용 (Cost)** | 예산 관련 | 예산 초과, 환율, 추가 비용 |
| **인력 (Resource)** | 인적 자원 관련 | 핵심 인력 이탈, 역량 부족, 가용성 |
| **범위 (Scope)** | 요구사항/범위 관련 | 요구사항 변경, 범위 확대 |
| **외부 (External)** | 외부 환경 관련 | 규제 변경, 벤더 이슈, 시장 변화 |

### 3. 리스크 평가 매트릭스 (확률 x 영향)

```
              영향 (Impact)
              Low    Medium    High
확률     High  | M    |  H     |  VH   |
(Prob.)  Med   | L    |  M     |  H    |
         Low   | VL   |  L     |  M    |
```

| 등급 | 설명 | 조치 |
|------|------|------|
| **VH (Very High)** | 즉시 조치 필요 | 경영진 에스컬레이션, 대응계획 즉시 실행 |
| **H (High)** | 적극 관리 | 주간 모니터링, 대응계획 수립 |
| **M (Medium)** | 주의 관찰 | 격주 모니터링, 대응계획 준비 |
| **L (Low)** | 수용 가능 | 월간 모니터링 |
| **VL (Very Low)** | 수용 | 분기 모니터링 |

### 4. 대응 전략 (Response Strategy)

| 전략 | 설명 | 적용 시기 |
|------|------|----------|
| **회피 (Avoid)** | 리스크 원인 제거 | 영향 VH, 회피 가능 시 |
| **전가 (Transfer)** | 제3자에게 이전 (보험, 외주) | 전문성 부족, 재무 리스크 |
| **완화 (Mitigate)** | 확률 또는 영향 감소 | 가장 일반적, H/M 등급 |
| **수용 (Accept)** | 리스크 인정, 비상계획 준비 | L/VL 등급, 비용 대비 효과 낮을 때 |

### 5. 리스크 모니터링

```markdown
## 리스크 추이 (Trend)
| 리뷰일 | 총 리스크 | VH | H | M | L | 신규 | 종료 | 변동 |
|--------|----------|-----|---|---|---|------|------|------|

## 상위 5개 리스크 (Top 5 Risks)
1. R-xxx: [설명] — 등급: [VH/H] — 대응: [전략]
2.
3.
4.
5.
```

## 출력 형식
- 프로젝트 규모에 따라 `/xlsx` (상세) 또는 `/docx` (요약) 선택
- Excel 출력 시: 리스크 등록부 시트 + 히트맵 시트 + 추이 시트
- Word 출력 시: 리스크 등록부 + 상위 리스크 + 대응계획

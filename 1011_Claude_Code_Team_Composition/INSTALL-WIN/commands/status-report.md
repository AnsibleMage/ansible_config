프로젝트 상태 보고서를 생성해주세요.

## 보고 대상
$ARGUMENTS (프로젝트명, 보고 유형: 주간/월간, 보고 대상: 경영진/고객/내부)

## 수행 작업
1. 프로젝트 현재 상태 파악
2. 보고 유형(주간/월간)에 맞는 템플릿 선택
3. 보고 대상(경영진/고객/내부)에 맞는 톤과 깊이 조정
4. 상태 보고서 작성 (/docx 또는 /pptx 활용)

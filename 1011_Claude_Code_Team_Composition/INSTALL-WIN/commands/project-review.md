지정된 프로젝트의 PM 산출물을 전체 리뷰하고 결과를 기록해주세요.

## 리뷰 대상
$ARGUMENTS (프로젝트명 또는 폴더 경로)

## 수행 작업
1. 리뷰 대상 프로젝트 폴더 확인
2. 산출물 목록 파악 (문서, 계획서, 보고서 등)
3. 전체 평가 수행:
   - 산출물 완전성 (필수 산출물 누락 여부)
   - 문서 품질 (일관성, 정확성, 가독성)
   - 프로젝트 관리 적절성 (WBS, 일정, 리스크)
   - 커뮤니케이션 충실도 (보고서, 회의록)
4. 프로젝트 최상위 폴더에 `PJ-[번호]_[프로젝트명]_[날짜].md` 생성
5. 등급 부여 (A/B/C/D) 및 결과 보고

## 평가 항목

### 1. 산출물 완전성 (Deliverable Completeness)
- [ ] 프로젝트 헌장 / 착수 보고서
- [ ] WBS / 작업 분해 구조
- [ ] 일정 계획 (간트차트 또는 일정표)
- [ ] 리소스 계획
- [ ] 리스크 관리 계획
- [ ] 주간/월간 보고서
- [ ] 이슈 로그
- [ ] 변경 관리 기록
- [ ] 최종 보고서 / 교훈

### 2. 문서 품질 (Document Quality)
- [ ] 용어 및 표기 일관성
- [ ] 수치/날짜 정확성
- [ ] 논리적 흐름
- [ ] 포맷 및 표준 준수

### 3. 프로젝트 관리 적절성 (Management Adequacy)
- [ ] 범위 관리 (Scope)
- [ ] 일정 관리 (Schedule)
- [ ] 비용 관리 (Cost)
- [ ] 품질 관리 (Quality)
- [ ] 리스크 관리 (Risk)

### 4. 커뮤니케이션 충실도 (Communication)
- [ ] 이해관계자별 보고 이력
- [ ] 이슈 에스컬레이션 기록
- [ ] 회의록 및 의사결정 기록

## 등급 기준
| 등급 | 기준 |
|------|------|
| **A (우수)** | 모든 항목 90% 이상 충족, 모범 사례 수준 |
| **B (양호)** | 주요 항목 80% 이상 충족, 소수 개선점 |
| **C (보통)** | 필수 항목 충족하나 개선 필요 다수 |
| **D (미흡)** | 필수 항목 미충족, 즉시 개선 필요 |

현재 프로젝트 전체를 리뷰하고 `~/.reviews/` 폴더에 기록해주세요.

## 리뷰 대상
$ARGUMENTS (프로젝트명 또는 현재 폴더)

## 수행 작업
1. `~/.reviews/` 폴더 존재 확인 (없으면 생성)
2. 프로젝트 구조 분석
3. 전체 평가:
   - 아키텍처 적절성
   - 코드 구조 및 일관성
   - 문서화 수준
   - 확장성 및 유지보수성
4. `~/.reviews/PJ-[번호]_[프로젝트명]_[날짜].md` 생성
5. 등급 부여 (A/B/C/D) 및 결과 보고

## 평가 항목
- [ ] 아키텍처 적절성
- [ ] 코드 구조 및 일관성
- [ ] 문서화 수준
- [ ] 확장성 및 유지보수성
